1. تنصيب الخادم الرئيسي (Server)

الخطوة 1: التحميل

حمّل ملف Setup.exe من صفحة البرنامج.

الخطوة 2: التثبيت

  1. انقر مرتين على Setup.exe
  2. اختر اللغة واضغط OK
  3. اضغط Next
  4. اختر Server / خادم من نوع التثبيت
  5. اختر مجلد التثبيت (اترك الافتراضي)
  6. اضغط Install وانتظر
  7. اضغط Finish

بعد التثبيت، السكربت يشغل كل شيء تلقائياً: قاعدة البيانات + الجدار الناري + الإعدادات

الخطوة 3: أول تشغيل

  • البرنامج يفتح تلقائياً
  • قاعدة البيانات تنشأ تلقائياً
  • المستخدم admin يخلق تلقائياً
  • الأقسام والورديات الافتراضية جاهزة

2. تنصيب الأجهزة الأخرى (Client)

الخطوة 1: نفس ملف Setup.exe

نفس الملف يُثبّت على كل الأجهزة

الخطوة 2: اختر Client

أثناء التثبيت، اختر Client / عميل بدل Server

هذا يعني: لا تثبيت PostgreSQL - فقط البرنامج

الخطوة 3: الاتصال بالخادم

  1. افتح البرنامج
  2. ستظهر نافذة إعدادات الشبكة تلقائياً
  3. في Server IP: اكتب عنوان الخادم
  4. اضغط Test Connection
  5. إذا ظهر ✓ متصل → اضغط Save

3. تسجيل الدخول

بيانات الدخول الافتراضية

اسم المستخدمadmin
كلمة المرورadmin123

غيّر كلمة المرور فوراً بعد أول دخول من قسم "المستخدمون"

4. إعدادات الشبكة

على الخادم:

Server IPlocalhost
Port5433

على الأجهزة في نفس الشبكة:

اعرف IP الخادم من الأمر ipconfig

Server IP192.168.1.10 (مثال)
Port5433

عبر الإنترنت (من بعيد):

  1. شغّل Cloudflare على الخادم
  2. يظهر رابط عام
  3. استعمله للوحة المراقبة فقط

5. تفعيل الترخيص

التجربة المجانية

30 يوم كاملة بكل المميزات - بدون أي قيود.

خطوات التفعيل:

  1. افتح الإعدادات
  2. انسخ Machine ID
  3. أرسله على واتساب: 0657200758
  4. استلم مفتاح التفعيل
  5. الصقه واضغط تفعيل

أنواع التراخيص:

النوعالمدة
شهري30 يوم
3 أشهر90 يوم
6 أشهر180 يوم
سنوي365 يوم
مدى الحياة∞

6. إدارة الموظفين

إضافة موظف:

  1. القائمة: الموظفون
  2. اضغط إضافة موظف
  3. الكود يتولد تلقائياً (EMP-0001...)
  4. أدخل الاسم واللقب
  5. اختر القسم والوردية والمنصب
  6. أدخل الراتب والعلاوات والخصومات
  7. اضغط حفظ

بحث وتعديل:

  • حقل البحث يبحث بالاسم أو الكود
  • انقر مرتين للتفاصيل
  • أزرار: عرض / تعديل / حذف

7. سجل الحضور + ZKTeco

إدخال يدوي:

  • القائمة: سجل الحضور
  • اضغط إضافة يدوي
  • اختر الموظف والتاريخ والأوقات
  • حدد الحالة

جلب من ZKTeco:

  1. اضغط جلب من ZKTeco
  2. أدخل IP الجهاز (مثال: 192.168.1.201)
  3. المنفذ: 4370
  4. اضغط فحص الاتصال
  5. ثم جلب السجلات

الجهاز والكمبيوتر على نفس الشبكة

8. الإجازات

طلب إجازة:

  1. القائمة: الإجازات
  2. اضغط طلب إجازة
  3. اختر الموظف والنوع
  4. حدد البداية والنهاية
  5. اضغط حفظ

موافقة/رفض:

  • انقر عرض على الطلب
  • اضغط موافقة أو رفض

الموظف في إجازة = لا يحسب غائب في الرواتب

9. الرواتب والضرائب

حساب الرواتب:

  1. القائمة: الرواتب
  2. اختر الشهر والسنة
  3. اضغط حساب الرواتب
  4. البرنامج يحسب تلقائياً
